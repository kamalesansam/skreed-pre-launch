## 4. Setting up the new machine

1. `git clone https://github.com/kamalesansam/skreed-pre-launch.git`, then `git -C skreed-pre-launch config user.name kamalesansam` and set Sam's email as the old clone had it. Commits use Sam's identity.
2. Node 24, then `npm ci`. Playwright runs in the installed Chrome (`CHROME_PATH`, `channel: 'chrome'`). Blender 5.2 is needed for sessions 3 and 4's renders only.
3. `pip install graphifyy`, then `npm run graph` in every checkout and worktree before exploring code (`CLAUDE.md`, graphify section).
4. On Windows, run every npm script through Git's bash: `npm --script-shell="C:/Program Files/Git/usr/bin/bash.exe" run <script>`. The `.claude/launch.json` entries `astro-dev-win` (port 4321) and `astro-dev-win-4322` already do this for the dev server. On a Mac or Linux none of that is needed.
5. One worktree per session, on its branch: `git worktree add .claude/worktrees/<name> <branch>`, then `npm ci` inside it. Worktrees do not share `node_modules`.
6. Then copy the carry folder's files to the places in section 3.
